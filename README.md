## Alpha 0.8 — დიდი განახლება

### ⚔️ სამი განსხვავებული მოკავშირე, შვიდკაციანი ჯარი

ყაზარმის აშენების შემდეგ ქვედა პანელის „⚔️ ჯარი“ ჩანართიდან შეგიძლია დაიქირავო:

| ჯარის ტიპი | ფასი | მოქმედება |
|---|---|---|
| 🛡️ ხმლიანი | 🪙35 🌲3 | წინ მიდის, ფარითა და ხმლით მტერს ებრძვის |
| 🏹 მშვილდოსანი | 🪙55 🌲5 | შორიდან ესვრის მტერს, ახლოდან იხევს უკან |
| 💚 მკურნალი | 🪙70 🌲7 | მცველებს და გმირს პერიოდულად სიცოცხლეს აღუდგენს |

ჯარის მაქსიმალური რაოდენობა **7** გახდა. ჯარის „წვრთნა“ **5 დონემდე** ზრდის მოკავშირეების გამძლეობას, ზიანს და მკურნალის ეფექტიანობას. ტალღებს შორის ჯარის გაძლიერება მეოთხე არჩევანადაც დაემატა.

### 🪵 ახალი მტრის ალყის მანქანა

ყოველი მეხუთე ტალღის ბოლოს მოდის **ტარანი** — ეტლზე დადგმული მძიმე საბრძოლო მორი ბორბლებით და რკინის თავით, რომელიც გალავანსა და ციხეს ძალიან ძლიერად აზიანებს. ტარანს თავისი HP ნიშნული აქვს. კვლავ არიან მტრის მშვილდოსნები, სწრაფი მტრები, მძიმე ჯარისკაცები და კაპიტანი გამაფრთხილებელი წითელი დარტყმის ზონით.

### 🏰 ციხის 5 დონე

„🛡️ დაცვა“ ჩანართიდან ციხის დონე 1-დან 5-მდე იზრდება. ყოველი დონის გაუმჯობესება მოითხოვს მონეტებსა და ხეს, ზრდის ციხის მაქსიმალურ HP-ს, შევსებას, კედლების გამძლეობას და ვიზუალურ დეკორაციას.

### 📯 ახალი აქტიური საბრძოლო უნარი

**„სამეფოს შეძახილი“** — ტელეფონზე ახალი მწვანე/ოქროსფერი ღილაკი, კომპიუტერზე **B**: ახლომდებარე მტრები 1.7 წამით ჩერდებიან, მოკავშირეებს ცოტაოდენი HP აღუდგებათ და 7 წამის განმავლობაში ჯარის შეტევა ძლიერდება. უნარის ხელახლა გამოყენებას სჭირდება 18 წამი.

### 📜 სამეფოს დავალებები და ქულები

- ოთხი განმეორებადი დავალება: დაამარცხე მტრები, გადაარჩინე მოსახლეობა, ააშენე შენობები, დაიქირავე მოკავშირეები
- დავალების დასრულებისას იღებ მონეტებსა და ზოგჯერ ხის რესურსს
- ბრძოლაში გროვდება **⭐ ქულები**; მოკლე ინტერვალში მტრების მოკვლისას მოქმედებს კომბო
- სამეფოს პროგრესი კვლავ ვრცელდება ტალღიდან ტალღამდე

### 💾 პროგრესის შენახვა და Alpha 0.7-ის მხარდაჭერა

- შენახვა/გაგრძელება ინახავს მოკავშირეთა **ტიპებს**, მათ HP-ს, შენობებს, რესურსებს, ჯარისა და ციხის დონეებს, ქულებს, დავალებებს და ტალღას
- **ძველი Alpha 0.7-ის შენახვა ახალ ვერსიაში ჩაიტვირთება** — ძველი ფაილის ასლი უცვლელი რჩება
- შუა ტალღის ნაცვლად თავიდან იწყება მიმდინარე ტალღა, მაგრამ შენახული განვითარება რჩება
- Player და Developer ცალ-ცალკე ინახება **იმავე ბრაუზერში**; სხვა ტელეფონზე ავტომატური სინქრონიზაცია ჯერ არ არის

### 🎨 ვიზუალური და ტექნიკური გაუმჯობესება

- ახალი 3D მოდელები მოკავშირე მშვილდოსნის, მკურნალის და მძიმე ტარანისთვის
- კაპიტნის/ტარანის გამძლეობის ნიშნულები, უკეთესი მინი-რუკა და შეტევების ინდიკატორები
- სამი მშენებლობის ჩანართი: დაცვა, სოფელი, ჯარი
- მობილურის ეკრანზე დალაგებული UI, დროებითი შეტყობინებები
- ისრებისა და ნაწილაკების გრაფიკული რესურსების გათავისუფლება, სტატუს-პანელის განახლების შემცირებული სიხშირე, მობილურისთვის ოპტიმიზებული რენდერი
- შენარჩუნებულია ორიგინალური ფონური მუსიკა, საბრძოლო ხმები, ცოცხალი მშვილდის ანიმაცია და ფირალის მსგავსი დინამიკური ჯოისტიკი

## მართვა

**Android:** ქვედა თავისუფალ სივრცეში თითის დაჭერით გამოჩნდება დინამიკური ჯოისტიკი. ქვედა მარჯვენა ღილაკები — სამეფოს შეძახილი, ხუთისრიანი შეტევა, Dash, მკურნალობა. სამი ჩანართიდან ააშენე ნაგებობები ან დაიქირავე მოკავშირეები. ⏸ — პაუზა/შენახვა.

**PC:** WASD/ისრები — მოძრაობა; Q კედელი, E კოშკი, F მონიშნული შენობის გაუმჯობესება, R გმირის გაძლიერება, G ხმლიანი, H მშვილდოსანი, J მკურნალი, B სამეფოს შეძახილი, V ხუთისრიანი შეტევა, Space Dash; 1/2/3 მშენებლობის ჩანართები, P პაუზა.

## ლოკალურად

```bash
python -m http.server 8765
```

Player: `http://localhost:8765`  
Developer: `http://localhost:8765/developer.html`

Three.js მოდული CDN-დან იტვირთება. საჭიროა ინტერნეტი თავდაპირველი ჩატვირთვისთვის. ეს ჯერ **ბრაუზერული პროტოტიპია**, არა Unity Android APK.
