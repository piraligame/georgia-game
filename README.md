# GEORGIA — სამეფოს დაცვა 🇬🇪

**Alpha 0.4** — დამოუკიდებელი 3D ბრაუზერული თამაში: ქართველი მშვილდოსანი იცავს ციხეს, აგროვებს მონეტებს და აშენებს თავდაცვით ნაგებობებს.

**ითამაშე:** https://piraligame.github.io/georgia-game/?v=0.4

**Developer:** https://piraligame.github.io/georgia-game/developer.html?v=0.4

## Alpha 0.4 — ახალი ცვლილებები

- **მშვილდის გაუმჯობესება:** უფრო დიდი და დეტალური 3D მშვილდი; სხეულისა და ხელების მოძრაობა; სიმის რეალური დაჭიმვისა და გაშვების ვიზუალური ციკლი; გასროლის შემდეგ ვიბრაცია.
- **ისრის ტრაექტორია:** ახალი ისარი იწყებს მოძრაობას მშვილდის პოზიციიდან, ბრუნდება ფრენის მიმართულებით და მტერს ხვდება.
- **საბრძოლო ხმები:** მშვილდის დაჭიმვა/გაშვება (ტყაპუნის/შხუილის ხმა), ისრის მოხვედრა, დაზიანება, მონეტა, მშენებლობა, გაუმჯობესება, დაშის მოძრაობა, ტალღის დაწყება და დამარცხება.
- **ახალი ფონური მუსიკა:** მშვიდი ორიგინალური მელოდია და ჰარმონია, რომლებიც Web Audio API-ით ცოცხლად გენერირდება; არ იყენებს სხვა თამაშის მუსიკას და არ საჭიროებს დამატებით აუდიო ფაილებს.
- **ხმის მენიუ:** მუსიკისა და ეფექტების დამოუკიდებელი ჩართვა/გამორთვა, არჩევანის შენარჩუნება ბრაუზერში.
- **Player/Developer:** იგივე სისტემები ორივე სათამაშო გვერდზე, ტელეფონსა და კომპიუტერში.

**მნიშვნელოვანი:** ბრაუზერის აუდიოპოლიტიკის გამო მუსიკა პირველად იწყება „თამაშის დაწყებაზე“ შეხების შემდეგ; შემდეგ თუ ტაბიდან დაბრუნდები, ერთჯერადი შეხება ხმას აღადგენს.

## წინა ვერსიის მექანიკები

დინამიკური ჯოისტიკი, 18 სამშენებლო წერტილი, ოთხდონიანი კედლები/მშვილდოსნის კოშკები, სხვადასხვა მტრის ტიპები, მტრის ნაკადები და ბოსი ყოველ მეოთხე ტალღაზე.

## მართვა

**ტელეფონი:** ქვედა თავისუფალ სივრცეში შეეხე ეკრანს და გაასრიალე თითი. მშენებლობის პანელიდან ააშენე კედლები ან კოშკები; ნაგებობის არჩევის შემდეგ გამოიყენე გაძლიერების ღილაკი. მუსიკისა და ხმის ღილაკები ეკრანის ზედა მარცხენა მხარესაა.

**კომპიუტერი:** WASD/ისრები — მოძრაობა; Q — კედელი; E — კოშკი; F — არჩეული ნაგებობის გაძლიერება; R — გმირის გაძლიერება; Space — Dash.

## ლოკალურად გაშვება

```sh
python -m http.server 8765
```
