# GEORGIA — სამეფოს დაცვა 🇬🇪

**Alpha 0.5** — დამოუკიდებელი 3D ბრაუზერული თამაში. მშვილდოსანი იცავს ქართულ ციხეს, აგროვებს მონეტებს, აშენებს გალავანს და აძლიერებს კოშკებს.

**Player:** https://piraligame.github.io/georgia-game/?v=0.5

**Developer:** https://piraligame.github.io/georgia-game/developer.html?v=0.5

## Alpha 0.5 — მნიშვნელოვანი განახლება

- **გმირის სახეცვლილი 3D მოდელი:** ცალკე მოძრავი ფეხები, ხელები, თავი, ტყავის სამოსი, ქამარი, ახალი მშვილდი და მშვილდოსნის აღჭურვილობა.
- **მოძრაობის ხუთი ძირითადი ანიმაცია:** Idle, Run, Aim, Draw/Release და Dash — განსხვავებული მხრების, ხელების, მშვილდის, სიმის, სხეულისა და ფეხების მოძრაობით.
- **მშვილდის დამიზნება:** მტრისკენ ბუნებრივი ტრიალი, მკვეთრი პოზიცია, გასროლის უკუცემა და მოკლე დაბრუნება ჩვეულ პოზაში.
- **გადაკეთებული ისარი:** უფრო მკაფიო ზომა, საფრთები, უკეთესი ისრის თავი, რეალური გასროლის წერტილი და მოხვედრის ვიზუალური ეფექტები.
- **რგოლების გასუფთავება:** გმირის ქვეშ ყვითელი რგოლი წაიშალა; დარჩა რბილი ჩრდილი. ციხის ირგვლივ არსებული ძველი რგოლიც წაიშალა; სამშენებლო ადგილებზე მსუბუქი L-მონიშვნებია.
- **უფრო ცოცხალი მტრები:** კიდურების მოძრაობა, დარტყმაზე რეაქცია, ფარები და განსხვავებული აბჯარი.
- **მიწისა და UI-ის დახვეწა:** კვადრატული, მოუხერხებელი ფერადი ლაქების ნაცვლად ბუნებრივი მრგვალი ბალახის ლაქები, პატარა და ნაკლებად შემაწუხებელი შეტყობინებები, უფრო მშვიდი ვიზუალური ფერები.
- **შენარჩუნებულია:** მშენებლობა და კოშკების 4 დონე, ფირალის ტიპის დინამიკური ჯოისტიკი, მშვილდის ხმა, ფონური ორიგინალური მუსიკა, საბრძოლო ხმები, მტრების ტალღები და ციხის დაცვა.

## მართვა

**მობილური:** თავისუფალ ქვედა ადგილზე შეეხე თითით — გაჩნდება ჯოისტიკი. მონიშნულ ადგილთან მიუახლოვდი და ააშენე, შენობაზე დაჭერით გააძლიერე.

**PC:** WASD / ისრები — მოძრაობა • Q — კედელი • E — კოშკი • F — არჩეული ნაგებობის გაუმჯობესება • R — გმირის გაძლიერება • Space — Dash.

## გაშვება

```sh
python -m http.server 8765
```

Browser Player: `http://localhost:8765`

Developer: `http://localhost:8765/developer.html`
