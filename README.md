## მთავარი ცვლილებები — Alpha 1.0

### 🪙 მშენებლობა ეკრანზე ღილაკების გარეშე

**ახლა ადგილთან მისვლით აშენებ.** ეკრანის დიდი „Build / Upgrade“ პანელები აღარ ჩანს.

1. დავითით მიდი მონიშნულ სამშენებლო ადგილზე და **დადექი მასზე**.
2. ადგილზე გამოჩნდება ნაგებობის სახელი, **დონის ფასი 🪙**, საჭირო ხე 🌲 და პროგრესის ზოლი.
3. მონეტები ავტომატურად, **ნაწილ-ნაწილ გადავა გმირიდან ადგილზე**, თან მცირე ოქროსფერი მონეტების ანიმაციით.
4. როცა საჭირო თანხა ჩაირიცხება, შენობა მაშინვე აშენდება. **ხე** თუ არ გაქვს, თამაში ჯერ მონეტებს არ ჩამოგაჭრის.
5. გასაძლიერებლად **გადი ამ ადგილიდან და ხელახლა მიდი**. დაგროვებული ნაწილობრივი გადახდა შეიძლება შენახვა/აღდგენასთან ერთად გაგრძელდეს.

ეს მუშაობს თავდაცვით ნაგებობებზე და სოფლის ეკონომიკურ შენობებზე. სოფლის თავისუფალ ადგილზე მისვლისას მარჯვენა ქვედა მხარეს მცირე ღილაკით „🔄 სხვა შენობა“ შეგიძლიათ შეცვალოთ სასურველი შენობა. სხვა დიდი პანელი არ ჩნდება.

### 🏘️ მეტი მშენებლობა და ეკონომიკა

წინა ვერსიის 64 თავდაცვით და 18 სოფლის ადგილს ვინარჩუნებთ — ჯამში **82** ადგილს. არსებობს ოთხი თავდაცვითი ტიპი: კედელი, მშვილდოსნის კოშკი, მახე და ბალისტა.

სოფლის არსებული ოთხი ტიპის გარდა დაემატა სამი ახალი შენობა:

- 🏺 **სავაჭრო** — მონეტების დამატებითი შემოსავალი
- ⚒️ **სამჭედლო** — ხის შემოსავალი და კოშკებისა და ბალისტების შეტევის გაძლიერება
- 💚 **სამკურნალო** — გმირისა და ჯარის სიცოცხლის აღდგენა

შესაძლებელია 7 ეკონომიკური ტიპის აშენება და 3 დონემდე განვითარება. თავისუფალ ადგილზე არჩეული ტიპი დამოუკიდებლად ინახება.

### 🏹 დავითი შავშეთელი და მოძრაობისას სროლის გასწორება

- დავითს აქვს ახალი ფერადი სამოსი, მუზარადი, მხრის დაცვის ელემენტები, ქართული სიმბოლოს მოტივი და მშვილდი
- **მოძრაობისას მიზანს წინა ხედვის კონუსიდან ირჩევს**, რათა უკან მდგარ მტერზე უცნაურად არ ისროლოს
- **გაჩერებულზე უახლოეს მტერს უმიზნებს**
- გასროლამდე გმირის სხეული ზუსტად მტრის მხარეს ტრიალდება; ისრის საწყისი წერტილი მშვილდთანაა
- დაჭიმული მშვილდის სიმი, მარჯვენა/მარცხენა მკლავის მოძრაობა და გასროლის უკუცემა შენარჩუნებულია და დაიხვეწა
- დამწყებისთვის გაუმჯობესებულია გმირის საწყისი ზიანი, სიცოცხლე და ციხის გამძლეობა

### ⚔️ ისტორიული ფენტეზის თავები

ეს არის **გამოგონილი, ეპოქებით შთაგონებული თავგადასავალი** და არა რეალური ისტორიული ბრძოლის რეკონსტრუქცია. დავით შავშეთელი არის თამაშის გამოგონილი პერსონაჟი.

- **თავი I — მონღოლთა ალყა (XIII საუკუნე):** მონღოლთა ჯარისკაცები, მხედრები, მშვილდოსნები და გენერალი
- **თავი II — შაჰ-აბასის სპარსეთი (XVII საუკუნე):** სპარსული/ყიზილბაშური რაზმები, სარდლები, შაჰ-აბასის თემატური სიუჟეტური ბოსი
- **თავი III — თბილისის განმათავისუფლებლები:** ისტორიული ფენტეზის კამპანიის გაგრძელება
- **თავი IV — ნარიყალას საბოლოო დაცვა:** ძლიერ მტრულ რაზმებთან ბრძოლა

ეპოქები **ცალ-ცალკე თავებად** არის წარმოდგენილი და განზრახ არ აცხადებს, რომ XIII საუკუნის მონღოლები და XVII საუკუნის შაჰ აბასი ერთდროულად უტევდნენ თბილისს. თავები ციკლურად გრძელდება.
