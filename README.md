## Alpha 1.03 — ახალი დიდი განახლება

- დინამიკური ჯოისტიკი **მხოლოდ ეკრანის მარცხენა ნახევრიდან** იწყება; მარჯვენა მხარეს საბრძოლო/სამშენებლო ღილაკები რჩება.

- ჩვეულებრივი მტერი ერთ პირდაპირ ისარზეა გათვლილი

- **შაჰ-აბასის თემატური სუპერბოსი — 10 პირდაპირი ისარი**
